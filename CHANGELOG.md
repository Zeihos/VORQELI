# Changelog

## 0.12.0 · One-Click Preview (18.10.2026)

- Полностью переработана главная панель с многослойным стеклянным интерфейсом и новым лого.
- Единая кнопка подключения и отключения DPI, Telegram и GeoHide.
- Поддержка трея, запуск в свёрнутом состоянии, запоминание последнего положения подключения.
- Регистрация автозапуска Windows через задачу с наивысшими правами только для защищённой установки под Program Files; fallback в HKCU Run для portable.
- Автоматическое скачивание закреплённого ZIP Flowseal 1.10.3 с SHA-256 и защитой от ZIP traversal.
- Встраивание Telegram Python core при сборке, без второй иконки upstream и ручных путей.
- Подключение GeoHide DNS, сохранение исходной конфигурации интерфейсов, восстановление при отключении.
- Создание Windows EXE и Inno Setup установщика в GitHub Actions с Node.js 24.
- 77 успешных автоматических тестов; все пять экранов открылись в виртуальном оконном окружении.
- Известные ограничения: внешние движки и инсталлятор требуют проверки на реальном Windows; профиль DPI экспериментальный; системный GeoHide пока использует обычный DNS IPv4, не обязательно DoH.
