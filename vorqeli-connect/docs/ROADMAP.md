# Roadmap

## v0.1 (implemented)
- Desktop shell and service reachability probes
- Saved settings, basic tests

## v0.2 (planned)
- Isolated module-controller interfaces (start/stop/status/events)
- Local MTProto subprocess wrapper with explicit consent, port checks and orderly cleanup
- Signed, version-pinned binary resource management

## v0.3 (planned)
- DPI engine wrapper with reversible OS changes and admin checks
- Per-service profiles, runtime log viewer, restart and crash recovery
- Real application-specific checks, not only HTTP HEAD

## v1.0 (planned)
- Windows installer, autoupdater with signatures, rollback and diagnostics export
- Accessibility and error handling, packaged tests across Windows variants
- Security and license audit; independently maintained branding
