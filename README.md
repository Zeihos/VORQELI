# VORQELI Connect

**VORQELI Connect 0.10.0 · Integration Preview** — настольный сетевой менеджер для Windows с русскоязычным интерфейсом. Репозиторий: https://github.com/Zeihos/VORQELI.

> ⚠️ Экспериментальная версия. Новые DPI и Telegram адаптеры запускают **локально предоставленные пользователем** компоненты Flowseal, но их работоспособность на конкретной Windows-машине пока не проверена. Это **не** стабильный релиз 1.0 и не гарантия обхода блокировок.

## Возможности

- Тёмный интерфейс (Tkinter), обзор, диагностика HTTPS/DNS/TCP, история и локальный журнал событий.
- **DPI / WinWS**: выбор оригинального распакованного пакета `Flowseal/zapret-discord-youtube`, запуск `bin/winws.exe` **непосредственно** с ограниченной TCP-стратегией `fake` или `multisplit`, без вызова `general*.bat` или установки службы.
- **Telegram**: запуск CLI `python -m proxy.tg_ws_proxy` из пользовательской копии `Flowseal/tg-ws-proxy`; локальный адрес `127.0.0.1`, конфигурируемый порт, постоянный локальный secret и ссылка `tg://proxy`.
- Отдельный контроль PID/завершения каждого движка, остановка своих процессов, файлы логов.
- Профили запуска обычного `.exe` (устаревший универсальный модуль), проверка SHA-256 выбранного файла.
- GitHub Actions: тесты и сборка `VORQELI-Connect.exe` на Windows.

## Установка самого VORQELI

**Вариант A: исходный код (Python 3.12, Windows 10/11)**

```powershell
py -m pip install -e ".[dev]"
py -m vorqeli_connect
```

**Вариант Б: Windows EXE**

На GitHub открыть **Actions → Windows build → успешный запуск → Artifacts → VORQELI-Connect-Windows**, распаковать и запустить EXE. `EXE` содержит интерфейс VORQELI, **не содержит** внешние движки, Telegram-пакет и Python для Telegram.

## Подключение Flowseal

Подробная инструкция: [docs/INTEGRATIONS.md](docs/INTEGRATIONS.md).

1. **DPI**: скачать оригинальный пакет с [релизов Flowseal zapret](https://github.com/Flowseal/zapret-discord-youtube/releases), распаковать в отдельную папку. На вкладке **DPI** выбрать папку с `bin/winws.exe`, `lists/list-general.txt` и `LICENSE.txt`. Выбрать FAKE/MULTISPLIT и вручную нажать «Запустить». Ограничено TCP 80/443, поэтому Discord голос/UDP и другие кейсы не охвачены. Может требоваться запуск с повышенными привилегиями.
2. **Telegram**: получить [официальные исходники Flowseal tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy), установить Python-зависимости **для этого пакета** (`py -m pip install -e .` из его каталога). На вкладке **Telegram** выбрать папку исходников, проверить путь к Python и запустить. В Telegram подключить локальную ссылку кнопкой в интерфейсе. Стандартный порт — 1443.
3. Для остановки нажмите **Остановить** в соответствующем разделе. При выходе VORQELI пытается остановить только запущенные им процессы. VORQELI **не** управляет чужими службами Windows.

## Тестирование

```powershell
py -m pip install -e ".[dev]"
py -m pytest -q
```

Локально протестирована логика Python и интерфейс импортируется, но запуск `winws.exe`/Telegram под Windows и с реальным подключением необходимо проверять отдельно. Внешних `.exe`, драйверов или исходников Flowseal в архиве нет.

## Безопасность и ограничения

- Приложение не скачивает сторонние исполняемые файлы, не отключает защиту Windows, не добавляет исключения антивируса и не устанавливает службу.
- Все внешние процессы запускаются только вручную; исполняемые файлы рекомендуется проверять по контрольным суммам из официального источника.
- Telegram secret хранится локально в `%APPDATA%/VorqeliConnect/settings.json` и передаётся внешнему Python-процессу в командной строке (это может быть видно локальным администраторам). Не публикуйте файл конфигурации и секрет.
- `tg://proxy` **не** является автоматическим подтверждением доступности Telegram: для успешной работы нужны установленные зависимости и реально работающий локальный сервер.
- DPI-адаптер предлагает **упрощённые собственные стратегии**, а не полную коллекцию профилей Flowseal. Некоторые функции оригинального пакета (`service.bat`, game filter, UDP/QUIC, hosts) не задействованы.
- Работа сети зависит от провайдера, прав и защиты Windows. Контроль завершения процесса не гарантирует автоматическое удаление системного драйвера, если драйвер был загружен.

Компоненты Flowseal имеют лицензию MIT, но в VORQELI **они не включены** и не перепакованы. Перед распространением пакета вместе с чужими бинарными файлами необходимо соблюдать лицензии и включить авторские уведомления.
