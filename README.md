# VORQELI Connect

Открытый проект Windows-приложения для диагностики сети и управления подключениями.

**Текущая версия: 0.3.0 (предварительная).** Доступны тёмный интерфейс, разделы «Обзор», «Диагностика», «Модули», «Настройки», экспорт результатов в JSON и сохранение порта. DPI-движок и Telegram-прокси **пока не интегрированы**; приложение не меняет сетевые параметры Windows.

## Запуск из исходников

Требуется Python 3.10+ с Tkinter:

```powershell
py -m pip install -e ".[dev]"
py -m vorqeli_connect
```

## Тесты

```powershell
py -m pytest -q
```

## Сборка для Windows

После загрузки файлов в **корень** репозитория GitHub Actions запустит тесты и PyInstaller. В разделе Actions → Windows build → Artifacts будет доступен `.exe`, если сборка успешно завершится. Наличие workflow само по себе не подтверждает успешную сборку.

## Структура

- `src/vorqeli_connect/` — интерфейс, диагностика и настройки.
- `tests/` — автоматические тесты.
- `.github/workflows/` — CI-сборка Windows.
- `docs/` — план и чек-лист релиза.

## Используемые проекты и лицензии

Планируется интеграция с [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) и [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy). Эти сторонние компоненты не включены в эту версию. Перед распространением интегрированных бинарников необходимо сохранить все лицензии и уведомления об авторских правах. Лицензия собственного кода проекта пока не выбрана.
