# VORQELI Connect

**VORQELI Connect 0.12.0 — Windows 10/11 · Integration Preview**

Одна кнопка для трёх модулей: Flowseal WinWS (DPI), локальный Telegram MTProto-прокси Flowseal и GeoHide DNS. Тёмный интерфейс со стилизованными полупрозрачными панелями и фирменным логотипом. Приложение работает в системном трее и сохраняет выбранное состояние при перезагрузке.

> ⚠️ Предварительная сборка. Все 77 модульных тестов выполнялись без реального Windows-драйвера, и полноценная связка на реальных сетях требует тестирования. **Не выпускайте публичный стабильный релиз до проверки на Windows.**

## Что доступно

- **Подключиться** — одна кнопка запускает все выбранные модули; **Отключить** — завершает запущенные программы и восстанавливает исходные DNS-настройки.
- **Трей** — крестик закрывает окно, но не завершает приложение или соединение. В трее: открыть, подключить, отключить, выйти.
- **Последнее состояние** (`desired_enabled`) сохраняется отдельно от фактического статуса. После перезапуска Windows VORQELI автоматически повторяет подключение, только если пользователь оставил его включённым.
- **Автозапуск** — после явного подключения приложение пытается зарегистрировать задачу Windows с повышенными правами. Для её создания обычно нужен один UAC-подтверждённый запуск. Если задача недоступна, используется HKCU Run с предупреждением: повторный UAC может понадобиться при входе.
- **DPI** — при первом подключении программа самостоятельно скачивает закреплённый ZIP-релиз `Flowseal/zapret-discord-youtube` 1.10.3 и сверяет SHA-256, не требует указать папку вручную. Запускает *экспериментальную простую TCP-стратегию*, **не точные `general*.bat`**. Эффект зависит от провайдера.
- **Telegram** — официальный Python-модуль `tg-ws-proxy` собирается внутрь `.exe` из закреплённого коммита `307a384...`; дочерний режим `--tg-worker` поднимает локальный прокси без второй иконки upstream. В настройках После первого успешного старта VORQELI автоматически один раз открывает ссылку `tg://proxy`, чтобы предложить Telegram Desktop подключить локальный прокси. В настройках VORQELI ссылка доступна повторно.
- **GeoHide** — Windows настраивается на опубликованные адреса GeoHide для активных физических IPv4-адаптеров. Предыдущая конфигурация DNS записывается до изменения и восстанавливается при отключении, если пользователь не менял её самостоятельно. Перед включением проверяется DoH. **На сетевых адаптерах в этой версии задаются IPv4-адреса обычного DNS; DoH пока используется только для проверки доступности GeoHide, а не как обязательное системное шифрование.** **GeoHide не VPN и не DPI-обход.**
- Диагностика HTTPS, история, журналы и настройки модулей.

## Быстрый старт

1. Откройте **Actions → Windows build** в https://github.com/Zeihos/VORQELI и скачайте успешный артефакт `VORQELI-Connect-v0.12.0-Windows`.
2. Распакуйте архив, запустите **`VORQELI-Connect-Setup.exe`**. Установщик разместит приложение в защищённой папке Program Files и добавит ярлык в меню «Пуск». Портативный EXE прилагается только для тестирования — для него тихий повышенный автозапуск заблокирован из соображений безопасности.
3. Запустите программу, подтвердите Windows UAC при первом запуске (если включены DPI/GeoHide), нажмите **«Подключиться»**. Программа сама загрузит WinWS и запустит Telegram при наличии соответствующих компонентов.
4. Закройте окно крестиком — оно уйдёт в трей. Нажмите «Отключить», чтобы сохранить отключённое состояние для следующего входа в Windows.
5. Если подключение частичное, посмотрите журнал: `%APPDATA%\VorqeliConnect\dpi-engine.log` и `telegram-engine.log`.

**Требование Windows:** драйвер WinDivert и изменения DNS требуют прав администратора. UAC нельзя законно обойти; при первом включении потребуется подтверждение. Задача повышенного автозапуска создаётся только после явного пользовательского действия и может блокироваться политиками организации.

## GeoHide DNS

`https://dns.geohide.ru:8443/` — информационная страница GeoHide. URL DoH для проверки доступности: `https://geohide.ru/dns-query`. Системный DNS в этой версии настраивается по IPv4-адресам, не через DoH. В этой версии IPv4-пресет — `159.194.200.33`, `37.230.192.51` (адреса DNS могут измениться; сверяйте с официальным сайтом). **DNS меняется системно, не только в рамках VORQELI.** При ручном завершении программы DNS восстанавливается. При аварийном завершении запасная копия остаётся в `%APPDATA%\VorqeliConnect\dns-restore.json`; восстановите DNS при следующем запуске через настройки. Изменения DNS, выполненные пользователем во время работы, намеренно не перезаписываются при отключении.

## Безопасность, лицензии и ограничения

- Файлы Flowseal загружаются только с официального GitHub release, сверяются с жёстко заданной контрольной суммой. На этапе сборки Telegram устанавливается из закреплённого коммита GitHub.
- Установка/обновление без отключения антивируса. WinDivert может распознаваться защитой Windows как драйвер сетевого перехвата.
- VORQELI не изменяет hosts-файл, не хранит Telegram-трафик и не отправляет телеметрию.
- Из-за особенностей отдельных браузеров собственные настройки Secure DNS могут переопределять DNS Windows.
- Сеть, DPI, DNS и локальный порт Telegram требуют **реального тестирования на Windows**, кроме тестов Python.
- См. [NOTICE.md](NOTICE.md), [быстрый старт](docs/QUICK_START.md), [план проверки](docs/WINDOWS_TEST_PLAN.md).
