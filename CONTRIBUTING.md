# Участие в разработке VORQELI Connect

Спасибо за интерес к проекту! Репозиторий публичный; обсуждения, ошибки и предложения приветствуются **на русском языке**.

## Как предложить изменение

1. Проверьте, нет ли уже похожей задачи в [Issues](https://github.com/Zeihos/VORQELI/issues).
2. Создайте отдельную ветку от актуального `main`, назвав её `fix/...`, `feat/...` или `docs/...`.
3. Избегайте крупных несвязанных изменений в одном Pull Request. Укажите назначение, риски и способы проверки.
4. Для изменений поведения добавьте регрессионные тесты; для UI — проверьте все шесть страниц и клавиатуру.
5. Откройте PR с заполненным шаблоном; используйте `Draft`, пока сборка не зелёная.

## Локальная проверка

На Windows с Python 3.12:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m compileall -q src scripts tests
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts/check_repo_layout.py
.\.venv\Scripts\python.exe scripts/verify_build_manifest.py
```

### Важно: контроль целостности

`BUILD_MANIFEST.json` содержит размер и SHA-256 каждого файла в `src/`, `scripts/`, `tests/`, `assets/`, `docs/`, `installer/`, `.github/` и критичных корневых файлов. `SHA256SUMS.txt` хранит перечень для контрольной сверки. При любом добавлении/изменении отслеживаемых файлов обновляйте **оба** файла и запускайте проверку. Не удаляйте контрольные тесты ради прохождения CI.

Версии должны совпадать в `pyproject.toml`, `src/vorqeli_connect/__init__.py`, `installer/VORQELI.iss` и имени артефакта GitHub Actions.

## Безопасность разработки

- Запуск тестов не должен скрытно менять системный DNS, HOSTS, реестр, автозапуск или устанавливать сетевой драйвер. Используйте временные файлы и моки.
- Для изменения DNS/HOSTS нужны согласие пользователя, резервная копия, проверка и возможность безопасного возврата.
- Не добавляйте личные конфигурации, секреты Telegram, IP пользователей, токены и приватные ключи.
- Не подменяйте доступность сайтов статусом процесса. Не обходите ограничения проверки цифровых подписей.
- Сторонние лицензии и атрибуции сохраняются в [NOTICE.md](NOTICE.md).
