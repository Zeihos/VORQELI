# VORQELI Connect v0.26.0 — Smart DPI

**Статус: экспериментально, не подтверждено испытаниями на Windows.**

## Что делает АВТО

Пользователь вручную выбирает **Настройки → Стратегия DPI → АВТО** и подключается главной кнопкой. При этом:

1. Загружается и проверяется официальный движок WinWS, как и в предыдущих версиях.
2. Запускается стратегия **FAKE**. Программа проверяет только прямой HTTPS-ответ от `https://discord.com/` и `https://www.youtube.com/` через HEAD, с обычной проверкой TLS-сертификата, без автоматического HTTP-прокси окружения.
3. Если оба сайта отвечают на HTTPS-запрос, программа не переключает стратегию.
4. Если не все сайты отвечают, WinWS **останавливается собственным контроллером**, затем пробуется **MULTISPLIT**. Результаты сравниваются; выигрывает большее количество HTTPS-ответов. При ничьей сохраняется FAKE (и может потребоваться перезапуск своего процесса).
5. На главной показывается активный профиль; если полный ответ не получен, в состоянии появляется предупреждение. Нажатие «Отключить» прерывает дальнейшие пробы и запускает безопасную остановку.

Каждая HTTPS-проба имеет таймаут 2,5 секунды. За один подбор максимум четыре запроса. Эти запросы видны соответствующим публичным веб-сайтам; собственный сервер VORQELI для диагностики не используется.

## Что АВТО **не** означает

- **Это не доказательство работоспособного обхода DPI**: сайт может быть доступен без WinWS, DNS может временно не отвечать, HTTP 403/405 может быть нормальным ответом доступного сервера.
- Это не проверка доступности Telegram MTProto и не диагностика всех сайтов / браузеров.
- Если оба профиля не могут открыть HTTPS, программа всё равно может оставить базовый FAKE активным **с предупреждением**. Статус процесса `on` означает только работающий WinWS, а не снятие блокировок.
- Выбор выполняется при новом подключении в режиме АВТО. Он **не** запускает постоянное сканирование в фоне, не делает бесконечные переключения и не подменяет пользовательское OFF.
- Используются упрощённые параметры WinWS, не полные оригинальные Flowseal batch-стратегии. Реальная эффективность должна быть испытана на целевой сети.

## Безопасность и проверки

- Работает только с двумя известными HTTPS-адресами (`smart_dpi.TARGETS`); пользовательские и локальные URL не принимаются.
- Никаких системных прокси, маршрутов, DNS, firewall, глобального завершения чужих процессов.
- Наблюдения в памяти, без записи истории проверенных сайтов или IP. Отчёт техподдержки включает выбранный **режим**, не HTTP-заголовки и не адреса.
- Unit-тесты через внедрение сетевого ответа проверяют сценарии полного ответа, частичного ответа, недоступности, падения движка, приоритета OFF и возврата к лучшему профилю.

## Обязательная Windows-приёмка до релиза

На тестовой Windows 10/11 с разрешением владельца компьютера и правами администратора: проверить FAKE и MULTISPLIT вручную, затем АВТО; выключение в середине пробы; отсутствие чужих WinWS; восстановление DNS после подключения и отключения; поведение трея и перезагрузки; различие между доступностью сайта и реальной работой сервисов. Записать версии Windows, сетевой адаптер и результат каждого сценария без учётных данных.
