# VORQELI Connect v0.37.0 — интерфейс, трей и UAC

## Реализовано

- Новый тёмно-синий интерфейс на существующем Tkinter Canvas (отрисовка через Pillow), без изменения сетевого движка.
- Шесть рабочих экранов: Главная, Диагностика, История, О проекте, Настройки, Сеть и стратегии DPI.
- Диагностика имеет ровно пять категорий: Discord, YouTube, Telegram, ChatGPT, Microsoft. Для Microsoft проверяются Copilot/Designer/Xbox, но показывается одна строка.
- Главная показывает **реальный результат контроллера модулей**, а не обещание доступности сайтов.
- Переключатели WinWS, Telegram и GeoHide; ALT1–ALT13, авторежим; IPv4 DNS и DoH; кнопки открытия DNS/HOSTS и восстановления DNS используют существующий код.
- Иконка окна и панели задач теперь выставляется через `iconphoto`; системный трей имеет команды открытия, подключения, отключения, диагностики, настроек и выхода. После ошибки backend есть ограниченный повторный запуск значка.
- Настройки `minimize_to_tray` и `admin_on_launch` сохраняются. По умолчанию GUI **запрашивает UAC при старте**; пользователь может отказаться, но DPI/DNS без прав администратора могут не работать. Команды `--doctor`, `--self-test`, `--tg-worker` и `--uninstall-cleanup` не вызывают новый UAC.
- Старая отрисовка сохранена в `_draw_legacy`, но по умолчанию используется новый интерфейс. Невозможно силой сделать значок всегда видимым вне скрытой области `^` Windows: это выбирается в настройках панели задач.

## Ограничения

- Окно поддерживает минимальную логическую область 1060×710; на маленьких экранах есть полосы прокрутки.
- Трей нужно проверить на **реальной Windows 10 и 11**, включая перезапуск Explorer и вход после автозапуска. Unit-тесты не доказывают, что Windows отобразила значок на панели задач.
- Запрос прав администратора работает только через штатный UAC Windows; приложение **не отключает UAC и не получает права без согласия пользователя**. Для автозапуска без запроса UAC сохраняется существующий безопасный механизм запланированной задачи из Program Files.
- Прохождение unit-тестов не гарантирует работу GeoHide/Claude и не означает прохождение ручных проверок подключения.
- Настройки протоколов/IPSet, которых нет в реальном API движка, не имитируются кликабельными элементами: параметры определяет выбранный профиль Flowseal.

## Локальная установка

1. Запустить патч на чистой исходной версии GitHub `main` v0.36.1. При уже изменённых исходниках патч остановится до записи.
2. `py -3.12 -m pip install -e ".[dev]"`
3. `py -3.12 -m pytest -q`
4. `py -3.12 scripts/check_repo_layout.py`
5. `py -3.12 scripts/verify_build_manifest.py`
6. `git diff --check` и просмотр `git diff --stat`.
7. Только после Windows CI тестировать собранный EXE.

Перед первым запуском новой версии рекомендуется полностью выйти из старой программы через трей. При отказе от UAC окно откроется без повышенных прав, сетевое подключение потребует UAC отдельно.
