# План ручной проверки Windows · VORQELI Connect 0.11.0

**Платформа:** Windows 10/11 x64. Автотесты не заменяют эту проверку. Перед тестами сохраните важные данные; при запуске winws могут потребоваться права администратора и могут возникнуть сетевые конфликты.

## Проверка приложения

1. GitHub Actions → Windows build → успешная сборка → Artifacts → `VORQELI-Connect-Windows`.
2. Распакуйте архив в отдельную папку, запустите `VORQELI-Connect.exe`.
3. Убедитесь, что открываются все 9 вкладок, текст помещается в окно 1080×700, кнопки не перекрываются.
4. Запустите «Диагностика» и «Проверить DNS/TCP». Убедитесь, что результаты отображаются, история обновляется и экспорт JSON не содержит Telegram-secret.
5. Без выбранных папок Flowseal нажмите «Проверить комплект» в DPI и Telegram. Приложение должно показать понятную ошибку, а не завершиться.

## Проверка DPI

1. Получите оригинальный пакет с https://github.com/Flowseal/zapret-discord-youtube/releases . Не скачивайте неизвестные исполняемые файлы.
2. Выберите распакованную папку. Кнопка «Проверить комплект» должна показать наличие файлов и выбранный режим.
3. При отсутствии прав запуск может завершиться; ошибка должна попасть в окно и журнал. При необходимости запуск VORQELI с правами администратора выполнять только осознанно.
4. Если процесс запущен — зафиксируйте PID, проверьте доступность нужного сайта до/после и затем нажмите «Остановить».
5. Убедитесь, что после остановки процесс `winws.exe`, который был запущен VORQELI, завершился. Проверяйте отдельно состояние других запущенных процессов и системного драйвера WinDivert.

## Проверка Telegram

1. Получите исходники с https://github.com/Flowseal/tg-ws-proxy и установите зависимости `py -m pip install -e .` в папке стороннего проекта.
2. Выберите исходники в VORQELI; проверьте Python и порт. Если порт занят — должна отображаться ошибка.
3. Запустите модуль, убедитесь, что появилась информация о PID и локальный порт начал отвечать. Это **не** подтверждение успешного MTProto-трафика.
4. Откройте ссылку в Telegram Desktop, активируйте прокси и проверьте получение/отправку сообщений.
5. Нажмите «Журнал». Секрет из VORQELI не должен появляться в открытом окне; полный сырой лог может содержать другие конфиденциальные данные.
6. Нажмите «Остановить», проверьте отсутствие дочернего процесса. Проверьте занятый порт и повторный запуск.

## Известные ограничения

- DPI-профили в VORQELI экспериментальные и не повторяют `general*.bat` Flowseal.
- Остановка процесса не гарантирует удаления/выгрузки драйвера WinDivert.
- Приложение не устанавливает Python, Flowseal или необходимые драйверы автоматически.
- Логи ограничиваются в окне просмотра до последних 64 КБ. Ротация на диске выполняется **только при следующем запуске** модуля.
- Windows-сборка и реальные соединения должны быть проверены отдельно после каждого существенного изменения.

## Как сообщить об ошибке

Запишите версию VORQELI, Windows, время, действие, текст ошибки и код завершения. Отправляйте только нужные **обезличенные** строки логов; удаляйте secret, токены, IP и личную информацию. Не публикуйте `settings.json`.
