# Windows QA — проверочный список для v0.16.0

Этот файл перечисляет **не выполненные здесь** проверки на настоящем Windows 10/11. Python unit-тесты не проверяют реальный сетевой обход.

## Перед тестами

- Используйте виртуальную машину или ПК с восстановлением системы и рабочим доступом в интернет.
- Сохраните исходные DNS-настройки сетевых адаптеров; убедитесь, что установщик проверен защитой Windows.
- Запустите GitHub Actions → Windows build. Проверьте успешный `--self-test` EXE и сборку Inno Setup.
- Установите `VORQELI-Connect-Setup.exe` в Program Files. Проверьте иконку и ярлыки.

## Подключение

1. Убедитесь, что DPI/TG/GeoHide включены в настройках.
2. Нажмите одну кнопку **Подключиться**, согласитесь с UAC. Проверьте загрузку релиза с SHA-256 и отсутствие ручного выбора папки.
3. Проверьте работу DPI на реальной сети (Discord, YouTube, UDP и браузер). Процесс, работающий в фоне, **не гарантирует** успешный обход.
4. Проверьте, что TG worker слушает 127.0.0.1:1443, Telegram Desktop предложил подключить прокси и нет второй иконки Flowseal в трее.
5. Проверьте, что GeoHide изменил DNS нужных интерфейсов, а тест GeoHide проходит. Проверьте именно DNS-ответ, а не только сайт.
6. Повторный клик **Подключиться** не должен порождать второй winws.exe/Telegram worker.

## Трей и Windows logon

1. Закройте окно крестиком: приложение должно быть в трее, а компоненты продолжить работу.
2. Нажмите на ярлык программы: должно открыться ранее запущенное окно, без второго экземпляра.
3. Перезагрузите ПК с включённым состоянием: задача Windows должна запускать VORQELI в трее и автоматически подключать выбранные компоненты без повторного UAC.
4. Нажмите **Отключить**, перезагрузите снова: программа должна остаться отключённой.
5. Отключите опцию автозапуска: задача должна удалиться, новая копия не должна запускаться при логоне.
6. Проверьте сценарии отказа UAC, нехватки прав на создание задания, ручного переноса portable EXE.

## DNS и восстановление

1. Для адаптера со статическим DNS проверьте полное восстановление исходных адресов.
2. Для DHCP DNS проверьте восстановление автоматической настройки.
3. В режиме GeoHide измените DNS вручную на другие адреса: VORQELI не должен перетирать изменения, сделанные пользователем.
4. Отключите интернет во время первой загрузки Flowseal: интерфейс должен показать ошибку, не отмечать подключение успешным.
5. Отмените скачивание кнопкой «Отключить»: не должно оставаться запущенных процессов.
6. Проверьте восстановление после аварийного завершения приложения и после обычного «Выход» из трея.
7. Проверьте IPv6 DNS и браузерный Secure DNS — они могут переопределять выбранный системный IPv4.
8. Перед удалением программы выйдите из трея; деинсталляция должна удалить задачу и вернуть DNS.

## Дизайн и дистрибутив

- Масштабирование 100, 125, 150 и 200%, тёмная тема Windows 10/11.
- Окно после закрытия/открытия и при перезагрузке — правильная сохранённая геометрия.
- Статусы без ложных «Подключено» при падении одного из модулей.
- Пакет проверен антивирусом, DLL и архивы скачаны только с официальных источников.
- Подписывание EXE/установщика перед публичным стабильным релизом.

## Надёжность подключения v0.16.0

1. После успешного подключения завершите **только принадлежащий VORQELI** Telegram worker. Убедитесь, что статус сменился на частичный и включилось восстановление с задержками 10/30/90 секунд.
2. Проверьте, что после трёх безуспешных попыток программа не продолжает бесконечно перезапускать компоненты.
3. Нажмите «Отключить» во время длительной первой загрузки DPI-пакета: OFF должен сохраниться и не сброситься после завершения потока загрузки.
4. Повторите проверку с быстро меняющимся состоянием окна и с двумя попытками «Отключить».
5. Убедитесь, что повышенная задача запускает EXE и DPI-движок только из Program Files, а не из AppData пользователя.
6. Проверьте восстановление GeoHide при повреждённой резервной копии и без повышения прав — никаких команд из файла не должно исполняться.
7. Обязательно проверьте IPv6/DoH браузера, DNS утечки и работу GeoHide с двумя сетевыми адаптерами.

## Дополнительные проверки v0.16.0

1. После коммита проверьте шаг `Verify Windows DPAPI secret storage` в Actions. Он должен пройти до PyInstaller.
2. После первого включения Telegram в `%APPDATA%\VorqeliConnect\settings.json` не должно быть plaintext `telegram_secret`. Должен присутствовать `telegram_secret_dpapi`, который расшифровывается тем же профилем Windows.
3. Скопируйте настройки в другой Windows-аккаунт: зашифрованный blob не должен расшифроваться, пользователь должен получить возможность подтвердить создание нового ключа, но остальные настройки должны сохраниться.
4. Переключайте FAKE/MULTISPLIT в GUI; после сохранения переподключитесь, проверьте точный режим запуска и не обещайте успешность стратегии без тестирования сайтов.
5. Проверьте отчёт `VORQELI-support.json`: никакого Telegram secret, локального пути, списка адаптеров, IP, журналов ошибок; только статусы выбранных модулей.
6. Проверьте новую графику, клавиши Alt+1–5 и F5 на Windows 10/11 при масштабировании 100%/150%/200%.
