# Проверка VORQELI Connect перед публикацией

Пункты ниже нужно выполнить на настоящей Windows 10/11 x64. Автоматические Python-тесты не заменяют интеграционную проверку драйвера и DNS.

## Обязательные сценарии P0

1. Установить Setup от обычного пользователя, проверить UAC и запись в Program Files.
2. Включить все 3 компонента одной кнопкой: DPI, Telegram, GeoHide. Убедиться, что в системе нет конфликта DNS/порта.
3. Закрыть окно крестиком, убедиться, что оно скрыто, а подключения остаются активны через трей.
4. Перезагрузить Windows при включенном состоянии. Проверить автоматический запуск и фактическое состояние каждого модуля.
5. Нажать «Отключиться», перезагрузить Windows. Убедиться, что обход не включился самопроизвольно.
6. Проверить ошибку загрузки DPI, отсутствие доступа к DNS, уже занятый порт Telegram: статус не должен быть зелёным.
7. Отключить GeoHide и сверить исходные DNS каждого адаптера, включая DHCP.
8. Убить приложение во время изменения DNS и проверить безопасное восстановление из резервной копии.
9. Выполнить установку поверх старой версии, удаление, повторную установку. Проверить что не остаётся повышенных задач Windows.
10. Проверить, что API токены/Telegram secret отсутствуют в экспортированных отчётах и журналах.

## Ограничения

Статус «Модули запущены» не означает доказанного обхода ограничений на конкретном сайте. Для этого нужны прикладные проверки. Нет цифровой подписи издателя, исходники пока предназначены для тестирования.
