# VORQELI Connect v0.40.0 — защита удаления и проверка HOSTS

## Назначение

Это кандидат на предрелизное тестирование, **не публичный стабильный релиз**.
Ранее подготовленный пакет v0.39.1 подключает официальный GeoHide RU HOSTS
по явному действию пользователя, с журналом для восстановления прежнего блока
VORQELI/Telegram. Но обычный деинсталлятор v0.39.0 ещё не знает об этих
новых системных изменениях. Если удалить его до отката HOSTS, у пользователя
могут остаться перенаправления на IP GeoHide без доступного интерфейса отката.

## Реализованные ограничения

- Перед деинсталляцией выполняется только **чтение** системного HOSTS и журнала
  `%APPDATA%/VorqeliConnect/geohide-hosts-restore.json`.
- Любой маркер `VORQELI OPTIONAL HOSTS` / `VORQELI GEOHIDE HOSTS`, даже
  повреждённый, **или** оставшийся журнал восстановления блокирует удаление.
- Неопределённые условия чтения также блокируют удаление. Логика запускается
  **перед** отключением автозапуска и восстановлением DNS, не оставляя программу
  наполовину удалённой.
- Для устранения препятствия запустить VORQELI от администратора:
  «HOSTS / ПРАВИЛА → GEOHIDE RU → ОТКАТИТЬ»; затем при наличии старого
  управляемого блока — «УБРАТЬ БЛОК» в общем менеджере HOSTS.
- После полного отката повторить удаление.
- Состояние HOSTS доступно в read-only CLI:
  `VORQELI-Connect.exe --geohide-hosts-status`. Выводит только JSON со статусом,
  числом доменов, признаком журнала и целостности, без пользовательских IP,
  файловых путей, секретов или содержимого HOSTS. Код 7 означает, что состояние
  невозможно безопасно проверить.
- CI smoke использует исключительно временные файлы и никогда не меняет
  системный HOSTS, DNS, WinWS, реестр или настройки пользователя.

## Что остаётся для v1.0

1. Зелёный полный `pytest` и GitHub Actions Windows с реальным EXE/установщиком.
2. Windows 10 и 11: установка/переустановка/удаление при активном GeoHide,
   после отката, после аварии и при конфликтующих HOSTS.
3. Корректное сохранение NTFS ACL файла HOSTS при редактировании, адаптеры DNS,
   восстановление после перезагрузки и переключения сетей.
4. Доказанная доступность ChatGPT/Claude/Microsoft по настоящему HTTPS и
   в браузере, а не только DNS/HTTP-заголовкам.
5. Подписанный Authenticode установщик/EXE и проверка SHA-256 после подписи.

**Важно:** HOSTS может перенаправлять соединения на сторонние серверы.
Один лишь ответ DNS/HTTPS не гарантирует безопасность трафика или доступность
авторизации. Не включать сетевые изменения автоматически при установке.
