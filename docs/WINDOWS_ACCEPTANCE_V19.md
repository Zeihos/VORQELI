# VORQELI Connect v0.19.0 — проверка на Windows

Тесты Python не подтверждают работу DPI/WinDivert или системного DNS на Windows.

## Обязательно перед публичным релизом
1. Установить `VORQELI-Connect-Setup.exe` в Program Files. Запустить без указания путей.
2. Подключить все модули одной кнопкой; проверить наличие `winws.exe`, локального порта Telegram и фактических IPv4 DNS GeoHide.
3. Отключить; убедиться, что дочерние процессы остановлены, а DNS восстановлен из резервной копии.
4. При включённом состоянии закрыть окно: программа должна остаться в трее.
5. Выполнить перезагрузку Windows, проверить восстановление только ранее выбранного состояния и отсутствие лишнего UAC при запуске из защищённой установки.
6. Перед перезагрузкой вручную отключить соединение; после входа в Windows оно должно остаться выключенным.
7. Имитация зависшего Telegram: процесс жив, порт не слушает. Проверить однократный управляемый перезапуск дочернего процесса.
8. Имитация сбоя GeoHide на втором сетевом адаптере: первый должен восстановиться, а нерешённые записи остаться в `dns-restore.json`.
9. Заполнить диск/отказать в записи `settings.json`: выход не должен отменять остановку процессов и восстановление DNS.
10. После обновления и удаления приложения проверить отсутствие осиротевших задач, драйверов и ошибочно сохранённых DNS.

**Ограничение:** пользовательская переносимая версия не обеспечивает автозапуск повышенной задачи без UAC. Для этого нужна стандартная установка с защищёнными ACL.

**Приватность:** диагностические отчёты не должны включать Telegram secret, содержимое журналов, локальные пути, IP и идентификаторы пользователя.
