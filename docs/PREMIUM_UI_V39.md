# VORQELI Connect v0.39.0 — утверждённый интерфейс

Версия v0.39.0 внедряет в настольное приложение шесть утверждённых макетов.
Это **локальные графические ресурсы для отрисовки UI**, без сетевой подгрузки.
Они не являются достоверными снимками здоровья соединения: живые статусы,
результаты HTTP, выбранные настройки, история и версия перерисовываются
из актуального состояния модулей. Демо-история на рисунках скрыта.

## Включено

- Безрамочный фиксированный размер окна; перетаскивание за верхнюю панель,
  закрытие и сворачивание, интеграция с треем и панелью задач Windows.
- Главная: реальное состояние компонентов и подключение/отключение.
- Диагностика: **5 категорий** — Discord, YouTube, Telegram, ChatGPT, Microsoft;
  403 не приравнивается к доступности аккаунта; Microsoft объединяет три проверки.
- История: реальные локальные события и фильтры, экспорт JSON.
- О проекте: сведения о компонентах и действительная ссылка GitHub.
- Настройки: динамические переключатели, действительные обработчики и UAC.
- Сеть и стратегии: ALT1–ALT13, AUTO, IPv4 DNS / DoH, HOSTS, восстановление.
- Отдельный журнал DPI/Telegram с тёмным оформлением, ограничением 64 КБ
  и удалением известных секретов.
- Новая V-иконка PNG (512), ICO (множество размеров), логотип в трее.
- Иконки Discord, YouTube, Telegram из Simple Icons (CC0-1.0):
  https://github.com/simple-icons/simple-icons (SVG предоставляются в папке brand).
  Дополнительные идентификаторы ChatGPT и Microsoft соответствуют макетам.

## Установка и безопасность

Встроенные двигатели WinWS, Telegram, GeoHide, HOSTS, сценарии UAC, реестр
и конфигурации сети **не изменялись**. Обновление содержит все ресурсы
офлайн и индексирует их SHA-256. Никакие пользовательские события не
подменяются демонстрационными данными. Рекомендуется до использования
сохранить исходный Git-коммит и убедиться, что он чистый.

После применения выполните `py -3.12 -m pytest -q`, `py -3.12 scripts/check_repo_layout.py`,
`py -3.12 scripts/verify_build_manifest.py`.
Финальный Windows EXE и поведение реальной панели задач нужно подтвердить
в GitHub Actions и на компьютере, где установлен продукт.

## Оговорки

PNG-композиции являются статической оформительской основой и масштабируются
при запуске. Они не редактируются через CSS/SVG. Переключатели и кнопки —
динамические Tk Canvas зоны, реальные вызовы остаются Python. Адреса
Telegram/VK-сообществ не выдуманы: пока точные ссылки не заданы, карточки
там информационные; приложение не ведёт на случайные сообщества.
