# Этапы до стабильного релиза (после v0.29.0)

**Релизный блокер:** восстановить исходники GitHub, получить успешную Windows CI-сборку, проверить WinDivert/DPI + Telegram + GeoHide на Windows, DPI-профили, автоматический запуск после перезагрузки, безопасную установку и удаление.

**Обновления v0.29.0:** реализованы opt-in проверка GitHub Release и скачивание с SHA-256, но **нет подписи издателя, полностью автоматического обновления или гарантированного отката**. До релиза 1.0: независимая подпись обновлений и безопасное обновление установщика.


**P0 — обязательно до публичного 1.0:**
- Восстановить и сохранить исходники в GitHub main; получить успешную сборку Actions.
- Проверить установку, обновление и удаление Windows EXE на реальном ПК.
- Проверить сочетание DPI + Telegram + GeoHide, включая доступность целевых сервисов.
- Проверить включение/выключение после перезагрузки и отсутствие двойного запуска.
- Проверить восстановление DNS после ошибок и аварийного завершения.

**P1 — качество и безопасность:**
- Уточнить семантику ошибок Планировщика задач (отсутствует / отказ в доступе / повреждена задача), проверить путь исполняемого файла и владельца задачи.
- Экспериментальный системный Windows GeoHide DoH добавлен в v0.27.0; до релиза проверить поддержку конкретных Windows 11, актуальность адресов провайдера, реальное шифрование и аварийное восстановление.
- Обеспечить безопасные подписанные обновления с проверкой целостности и откатом.
- Добавить автоматическую проверку эффективности DPI-стратегий на сервисах, а не только статус процесса.
- Отработать переход между Wi-Fi и Ethernet, засыпание/пробуждение, смену профиля Windows.

**P2 — премиальный UX:**
- Системная тёмная оконная рамка/Mica (запрашивается в v0.28.0) должна пройти Windows-приёмку; **полное нативное стекло клиентской области ещё не реализовано**.
- В v0.28.0 добавлены Tab/Shift+Tab, Enter/Space, видимый фокус и прокрутка компактных окон; следующий этап — настоящая UI Automation доступность для экранных дикторов и корректное масштабирование всех шрифтов/изображений.
- Улучшить первый запуск, обучающие подсказки и фирменные анимации, не отвлекая от одной кнопки.
- Сайт, документация, цифровая подпись готовой сборки и безопасная публикация релизов.

Статус: подробный тест-план текущей версии — `docs/WINDOWS_ACCEPTANCE_V23.md`. Успешные unit-тесты **не заменяют** Windows-приёмку.

### Состояние v0.26.0
- Smart DPI: добавлена **первая экспериментальная** автоматическая оценка двух профилей по ограниченному HTTPS-пробированию. Это **не** подтверждённая адаптация к блокировкам и не основание считать P1 полностью закрытым.
- Следующие блокеры: полноценная Windows-приёмка / UAC / установка и удаление / реальный автозапуск; системный GeoHide DoH; безопасные обновления и подпись.

### Состояние v0.27.0
- DoH реализован **условно** при поддержке Windows DnsClient, без неявного перехода на UDP, с восстановительным журналом глобальных записей. **Не проверен на реальном Windows 11.**
- Критические P0-блокеры остаются прежними: GitHub main, успешный EXE/инсталлятор в Windows Actions, тест DPI+Telegram+GeoHide, перезагрузка и восстановление.

### Состояние v0.28.0
- UI: 29 новых unit/regression тестов + офлайн GUI smoke с Tab и компактной прокруткой. Исправлено перекрытие GeoHide на минимальной высоте.
- DWM: тёмная рамка и Mica запрашиваются на поддерживаемых версиях Windows по принципу best-effort. Реальное отображение не проверено на ПК, а внутренние панели остаются отрисованными Pillow.
- Публичный релиз **всё ещё заблокирован** отсутствием проверенной Windows-сборки, сетевыми испытаниями и проверкой автозапуска после перезагрузки.
