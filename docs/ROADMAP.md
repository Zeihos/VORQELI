# План развития VORQELI Connect

**Текущий этап:** `v0.41.0 RC` — рабочая предрелизная ветка Windows-приложения, ещё не стабильный выпуск `1.0.0`.

## Уже автоматизировано

- [x] Полный проект размещён в GitHub.
- [x] Windows Actions собирает EXE и Inno Setup-установщик.
- [x] Проверка Python-синтаксиса, регрессионные тесты и контрольный манифест SHA-256.
- [x] Безопасные CI smoke-сценарии для автозапуска, DPAPI, DNS/DoH и установки/удаления.
- [x] Настоящий шестиэкранный Tkinter-интерфейс с Premium Dark и доступными кнопками.

**Эти пункты не подтверждают реальную эффективность сетевого обхода.**

## P0 — обязательно до v1.0.0

- [ ] Испытать установленный EXE на реальных Windows 10/11 x64 с правами администратора.
- [ ] Испытать WinWS / DPI на разных сетях, проверить ложноположительные результаты HTTPS-проверок.
- [ ] Проверить локальный Telegram MTProto и отдельно Telegram Web.
- [ ] Проверить GeoHide IPv4 DNS/DoH, официальный HOSTS, откат после ошибок и конфликт с ручными изменениями.
- [ ] Испытать перезагрузку Windows в состояниях ON и явно выбранном OFF, восстановление после сна и смены адаптера.
- [ ] Проверить компактный UI, 100/125/150/200% DPI, Tab/Enter/Space, повторные клики, трей и многоэкранность.
- [ ] Провести внешний аудит комплектных лицензий и обеспечить подпись EXE/Setup доверенным сертификатом издателя.
- [ ] Проверить процедуру безопасного обновления, удаления и восстановления конфигурации без потери пользовательских настроек.

## P1 — после стабильного релиза

- [ ] Улучшить доступность UI Automation для экранных дикторов.
- [ ] Расширить диагностические сценарии при смене сети/адаптера и нескольких сетевых интерфейсах.
- [ ] Повысить наблюдаемость и качество журналов без утечки секретов.
- [ ] Автоматизировать сбор проверяемых отчётов об ошибках с явным согласованием.

## Правила выпуска

Стабильная `1.0.0` допускается только после закрытия всех P0. Новые версии не следует называть «готовыми» по одному зелёному CI. Последний регламент: [RELEASE_VALIDATION.md](RELEASE_VALIDATION.md). Исторические материалы сохранены в `docs/` и `CHANGELOG.md`.
