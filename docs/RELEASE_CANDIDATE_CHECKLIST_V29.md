# VORQELI Connect — Release Candidate (v0.29.0 checkpoint)

Выполнение Python-тестов и успешная упаковка ZIP — **не подтверждение работоспособности Windows-сетевого приложения**.

## P0 — требуется до первого публичного релиза 1.0

- [ ] Ветка `main` GitHub содержит полный проект с `.github`, `src`, `scripts`, `tests`, `installer`, `assets`, `docs`, `pyproject.toml`.
- [ ] GitHub Actions для v0.29.0 успешно выполняет зависимости, Python-тесты, Windows DPAPI smoke, тест реестра и безопасное чтение возможностей DoH.
- [ ] GitHub Actions действительно собирает EXE и Inno Setup установщик; smoke tests запуска EXE, установки и удаления проходят.
- [ ] На реальном Windows 10/11 проверены UAC, WinDivert, DPI FAKE/MULTISPLIT/AUTO, локальный Telegram и GeoHide IPv4 DNS/DoH.
- [ ] Проверено подключение и отключение всех трёх модулей одной кнопкой, включая частичную ошибку и переподключение.
- [ ] Проверен полный выход из трея, выключение системы с подключением ON и OFF, перезагрузка и переключение сетевых адаптеров.
- [ ] Проверено восстановление DNS в сети с DHCP, статическими IPv4 и несколькими адаптерами, а также аварийное восстановление.
- [ ] Программа не сообщает «работает обход», если проверен только факт существования процесса.
- [ ] Изданы сертификат и процедура подписи EXE/установщика либо подписанный манифест с закреплённым доверенным ключом; проверка подписи встроена до принятия обновления.
- [ ] Опубликован тестовый Github Release с ожидаемыми assets, digest и контрольной суммой; проверено скачивание из старой версии и ручное обновление без потери настроек.
- [ ] Проверена процедура отмены или отката проблемной версии без утери оригинальной конфигурации DNS.

## P1 — дополнительная полировка

- [ ] Проверить UI Automation и экранный диктор; текущее Canvas-управление обеспечивает только клавиатурную навигацию.
- [ ] Проверить многомониторность, высокие DPI-масштабы и Mica на Win 11.
- [ ] Проверить подписи третьих сторон, соответствие лицензиям, персистентность логов и уязвимости зависимостей.

**Решение о релизе 1.0 допускается только после P0.**
