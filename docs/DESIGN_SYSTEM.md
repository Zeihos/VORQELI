# VORQELI Design System (v0.28.0)

## Визуальная система

- Основной фон: почти чёрный индиго (`#090D1A`), фиолетовое атмосферное свечение и приглушённые синие слои.
- Основной текст: `#F5F6FF`; дополнительный: `#A7AEC8`.
- Акцент: `#9475F6` и `#AF9AFF`. Состояния: работает `#82DEC9`, частично `#FAD39A`, ошибка `#FC9DBA`, ожидание `#86BFFF`.
- Скругления панелей 23–29 px, кнопок ~15 px; у кнопок многослойная вертикальная заливка, собственный альфа-канал, тонкая обводка и верхний блик. Стекло композитится Pillow поверх собственного фона; это не нативный Windows Acrylic.
- Макет: фиксированная левая панель, отзывчивая правая сетка из трёх компонентов. Логическая площадь макета 1060×710 px; на маленьком/масштабированном экране само окно может быть меньше, поэтому Canvas показывает прокрутку по обеим осям. Рекомендуем 1200×760 и выше.

## Правила интерфейса

1. На главной — **одно основное действие**, его нельзя нажимать повторно во время операции.
2. Не показывать «обход точно работает» по одному лишь наличию запущенного процесса. Текст «Компоненты работают» означает состояние локальных модулей.
3. Ошибки не скрывать: показывать частичную работу, предоставлять диагностику и журналы.
4. Настройки компонент сохраняются сразу, но для их применения к активному соединению требуется переподключение.
5. Закрытие окна скрывает его в трей, а команда «Выход из приложения» останавливает модули и пытается восстановить DNS.
6. Программа не должна самостоятельно понижать защиту Windows или отключать антивирус.
7. Клавиатура: Escape — трей; Ctrl+, — настройки; Ctrl+D — диагностика; Ctrl+Enter — подключить/отключить; Tab / Shift+Tab — обход доступных кнопок; Enter / Space — действие; Left / Right — смена фокуса.

## Ограничения текущего GUI

Canvas-кнопки поддерживают мышь, Tab/Shift+Tab, видимый фокус и клавиатурную активацию. **Однако Canvas ещё не предоставляет системные UI Automation роли экранным дикторам.** На Windows 11 запрашивается тёмная системная рамка/Mica у DWM — клиентская область остаётся собственным рендером Pillow без настоящего прозрачного Acrylic. Windows может проигнорировать настройки оформления. Экранные снимки получены из тестового графического окружения.

## v0.15 — Liquid Dark

Вдохновение: визуальная простота первого экрана Ded Proxy и структурная ясность панелей REG.RU; без прямого копирования. Кнопки теперь рисуются Pillow и композитятся поверх собственного фона. Фирменный тёмный индиго, фиолетовые градиенты и стеклянные карточки сохраняются. Выбор режима DPI в настройках, новая кнопка отчёта, улучшенные подсказки. Горячие клавиши Alt+1…5 для пяти разделов, F5 для диагностики. Настоящее системное размытие Mica/Acrylic, Поддержка UI Automation для экранных дикторов и полное клиентское Mica/Acrylic остаются в разработке; Tab-навигация и управление без мыши добавлены в v0.28.0.
