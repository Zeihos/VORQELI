# VORQELI Connect v0.40.6 RC — безопасное восстановление GeoHide

## Причина выпуска

1. После сбоя между сохранением журнала GeoHide и заменой системного HOSTS
   мог остаться журнал без управляемого блока. Менеджер возвращал `False`,
   а защитный установщик справедливо блокировал удаление из-за журнала.
2. При отключении GeoHide сохранённый блок Telegram мог повторно добавлять
   домены, для которых пользователь уже ввёл собственные записи в HOSTS.
3. Двойное нажатие «ВОССТАНОВИТЬ DNS» порождало параллельные PowerShell-операции
   над одним резервным файлом; исключение восстановления могло сообщать об успехе.

## Что изменено

- Явное действие «Убрать GeoHide» в менеджере HOSTS восстанавливает состояние
  после неполной записи **только** если блока GeoHide уже нет, старого блока
  VORQELI тоже нет, журнал соответствует схеме и содержит корректные SHA-256.
  В этом случае HOSTS остаётся побайтно неизменным: удаляется только осиротевший
  журнал восстановления. При ошибке чтения/конфликте операция прекращается.
- При восстановлении старого Telegram-блока проверяется пересечение доменов
  с ручными записями вне управляемых блоков. При совпадении откат останавливается
  без перезаписи HOSTS или журнала, требуя ручной проверки.
- Запрос восстановления DNS блокируется пока идёт другое сетевое задание,
  отключение, выход или уже выполняется восстановление. Кнопка отображает
  «ВОССТАНАВЛИВАЕМ…» и становится неактивной. Состояние сбрасывается на Tk-потоке
  через событие `dns_restore_done` даже если Windows отклонила операцию.
- Если резервных DNS-настроек нет, программа больше не сообщает об успешном
  восстановлении.

## Ограничения

- Обновляющий патч не затрагивает реальный HOSTS, сетевые адаптеры или реестр.
- Автоматического восстановления/перезаписи пользовательского HOSTS нет.
- Фактическое поведение на Windows 10/11, административные права UAC, драйверы,
  антивирус, GeoHide, WINWS и сетевые сервисы требуют отдельной приёмки.
- Перед выпуском 1.0 обязательны полный pytest, успешный Windows CI,
  тесты установки/удаления и проверенная цифровая подпись обоих EXE.
