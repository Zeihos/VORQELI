# VORQELI Connect 0.40.3 RC — реальная компоновка небольших окон

- Исправлена незаметная регрессия из 0.40.1/0.40.2: `_sync_scrollbars(cw,ch)` устанавливал область прокрутки равной окну, то есть в компактном режиме полос прокрутки вообще не было. Кнопки и шрифт вместо этого уменьшались до нечитаемых размеров.
- Tkinter Canvas теперь масштабирует 1536×1024 сцену с единым коэффициентом по обеим осям, минимум 0.80; при недостающем месте устанавливает scrollregion в истинных размерах отрисованной сцены. Tab/Shift+Tab и функция `reveal_target` из существующего приложения могут прокручивать к сфокусированному элементу.
- Исправлен статус `overall='error'`: центральный индикатор и текст не маскируют ошибку под обычный OFF.
- Состояние `overall='connected'` трактуется строго как запуск выбранных локальных компонентов, а не обещание доступности Discord/YouTube/ChatGPT.
- Новые автоматические проверки компактного экрана, отсутствия геометрических искажений, читаемых размеров основных кнопок и корректных статусов.
- Сеть, GeoHide, HOSTS, Telegram, автозапуск и Windows-права в 0.40.3 не меняются.

## Перед релизом

Нужно выполнить полный `pytest`, GitHub Actions Windows build и ручную приёмку EXE на Windows 10/11: компактный экран, Windows DPI 100/150/200%, Tab/Shift+Tab, мышь, scrollbars, tray, Alt+Tab и работа модулей.
