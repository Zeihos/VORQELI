# VORQELI Connect — интерфейс v0.28.0

## Визуальный стиль

- Темная палитра индиго с фирменным фиолетовым, многослойными градиентами и глянцевыми стеклянными карточками (Pillow). Логотип, основные статусы и одна кнопка подключения не изменялись.
- Windows 11: best-effort запрос `DWMWA_USE_IMMERSIVE_DARK_MODE`, `DWMWA_WINDOW_CORNER_PREFERENCE` и `DWMWA_SYSTEMBACKDROP_TYPE=DWMSBT_MAINWINDOW` для **системной** оконной рамки. На Windows 10 запрашивается поддерживаемый тёмный заголовок; ошибки DWM не влияют на подключение.
- Это **не** системный Acrylic поверх всего пользовательского интерфейса: Tk Canvas рисует непрозрачную клиентскую область, которой управляет Pillow.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `Tab` / `Shift+Tab` | Переключение между активными элементами текущей страницы, включая боковое меню |
| `Enter` / `Пробел` | Активация выбранной кнопки (фокус обозначен светлой обводкой) |
| `←` / `→` | Предыдущий / следующий доступный элемент |
| `Alt+1..5` | Главная / Диагностика / История / Настройки / О проекте |
| `Ctrl+Enter` | Подключение / отключение |
| `F5` | Диагностика |
| `Ctrl+,` | Настройки |
| `Escape` | Свернуть в трей; при отсутствии рабочего трея — на панель задач |

Недоступные/заблокированные кнопки не попадают в Tab-порядок. При обновлении статуса фокус старается остаться на элементе с прежним порядковым номером. Переход на другую страницу сбрасывает выбор.

## Небольшие дисплеи

- Если рабочее пространство из-за высокого DPI-масштаба меньше 1060×710 логических пикселей, окно уменьшается до доступных габаритов (с отступом от края монитора), а содержимое остаётся прокручиваемым.
- Вертикальная прокрутка: колесо мыши. Горизонтальная: `Shift` + колесо. Доступны видимые системные полосы прокрутки, когда их требуется показать.
- Смена активной кнопки с клавиатуры автоматически прокручивает область к ней.
- Кнопки GeoHide больше не перекрываются с подписью у нижней границы страницы «Настройки».

## Ограничения и проверки

- Canvas всё ещё не предоставляет системные UI Automation элементы экранному диктору. Для полноценной доступности нужен следующий отдельный рефакторинг либо нативный UI-фреймворк.
- DWM-заголовок и Mica не были проверены на реальной Windows в данной среде; Microsoft может изменять поддержку или отключить визуальные эффекты настройками ОС.
- В `tests/test_ui_navigation_v28.py` проверяется циклическая навигация, раскрытие кнопки через прокрутку, геометрия на маленьком экране и список DWM-атрибутов.
- В `scripts/gui_keyboard_smoke.py` проверяются реальные события Canvas и прокрутка под виртуальным графическим сервером. Для локальной проверки в Windows выполнить `python scripts/gui_keyboard_smoke.py` в интерактивной сессии.
