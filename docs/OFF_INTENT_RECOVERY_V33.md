# VORQELI v0.33.0 — надёжность явного отключения

## Для пользователя

- **Выключить**: сначала сохраняется независимый флаг `settings.json.off-intent`, затем `settings.json` с `desired_enabled=false`.
- Если питание пропадёт **после сохранения флага**, но до замены JSON, приложение при следующем входе выберет **OFF**, даже если старый JSON содержит ON.
- **Подключить**: сначала надёжно записывается ON в JSON, только потом удаляется OFF-флаг. Прерванная запись ON безопасно оставляет OFF для следующей загрузки.
- Флаг содержит только `OFF`, не хранит секретов, IP-адресов или персональных путей. Присутствие флага можно увидеть в `--doctor` как `explicit_off_guard: true`.
- Самостоятельно удалять флаг **не нужно**; нажмите «Подключиться» в приложении, чтобы безопасно изменить состояние.

## Отказы и границы гарантии

- Повреждённые `settings.json` и `.bak` интерпретируются как OFF, как и прежде.
- Если запись флага вообще невозможна (полный диск/нет доступа), программа сообщает об ошибке. Даже при такой ошибке команда отключения должна остановить собственные процессы, но гарантировать OFF **после перезагрузки** нельзя.
- Успешная запись + fsync снижает риск потери состояния, однако драйвер/прошивка диска и системные сбои могут нарушать гарантии устойчивости; заявлять абсолютную защиту от потери питания нельзя.
- Windows UAC, фактическое восстановление автозапуска и корректность прав пользователей необходимо проверить на реальном компьютере.

## Windows CI (без сетевых изменений)

```powershell
python scripts/windows_off_intent_smoke.py
python -m pytest -q
```

Скрипт работает только с временными файлами. Не запускает WinDivert, Telegram, не меняет DNS, задачи Планировщика или реестр.

## Ручное подтверждение

1. Установите подписанную тестовую сборку и нажмите «Подключиться».
2. Нажмите «Отключиться», дождитесь остановки всех компонентов.
3. Перезагрузите Windows и подтвердите `desired_connection: off` через `--doctor` и в UI.
4. Вновь подключитесь, перезагрузите Windows и подтвердите, что выбранное ON-состояние восстановлено, если автозапуск включён.
5. Проверьте реакцию на недоступный путь настроек: явное сообщение об ошибке и остановка процессов без ложного статуса сохранения.

Ни один из этих реальных Windows-тестов не считается выполненным локальными Python-тестами.
