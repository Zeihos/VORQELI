# VORQELI Connect 0.35.0 — Flowseal ALT и HOSTS

## Стратегии DPI

Вместо двух экспериментальных профилей FAKE/MULTISPLIT приложение поддерживает **оригинальные настройки `general (ALT).bat` (ALT1) и `general (ALT2).bat`–`general (ALT13).bat`** из SHA-256-проверенного архива Flowseal 1.10.3. BAT-файлы **не выполняются**. Программа анализирует их параметры, запрещает произвольные команды и запускает собственный `bin/winws.exe` в режиме управляемого дочернего процесса.

- `АВТО · ALT1–13` — последовательно проверяет `ALT2 → ALT6 → ALT11 → ALT12 → ALT13 → ALT4 → ALT3 → ALT8 → ALT9 → ALT7 → ALT10 → ALT1 → ALT5`. Это порядок тестирования, а **не универсальный рейтинг**. ALT5 отмечен upstream как `NOT RECOMMENDED`.
- `ВЫБРАТЬ ALT` — ручной выбор любого профиля. Применяется после переподключения, сохраняется в настройках.
- Если после установки профиля YouTube и Discord не отвечают, другие профили проверяются по очереди. Вращение между профилями прекращается, когда обе фиксированные HTTPS-цели возвращают ответ. Результат не гарантирует работоспособность обхода в браузере/десктопе.
- В исходных профилях `service.bat` создаёт пользовательские списки и переменные игровых фильтров. В целях безопасности `service.bat` не выполняется: отсутствующие необязательные пользовательские файлы пропускаются, переменные игровых портов и соответствующие блоки не включаются. Основные правила TCP/UDP/QUIC и Discord сохраняются. Это не побайтовый запуск `.bat`.
- Процессы запускаются последовательно; при переключении VORQELI останавливает только собственный DPI-процесс. Нет `taskkill /IM winws.exe`, `cmd /c` или запуска произвольного BAT.

## Дополнительные HOSTS-правила

Предоставленные пользователем 241 записи находятся в `assets/VORQELI-hosts-optional.txt`. **Они не являются DNS-конфигурацией GeoHide**, а фиксированные IP могут устареть. GeoHide DNS использует резолвер, который не допускает загрузки произвольных `hosts`-записей в удалённый сервис. Перенос таких записей в системный HOSTS — отдельный ручной шаг, явно подтверждаемый пользователем.

В настройках кнопка `HOSTS · ДОПОЛНИТЕЛЬНО` показывает совпадающие, отсутствующие и конфликтующие записи. Только после согласия приложение добавляет отсутствующие домены в блок `# VORQELI OPTIONAL HOSTS START/END`, а удаление затрагивает **только этот блок**, сохраняя ручные записи. Если обнаружены конфликты, операция блокируется. Для редактирования системного HOSTS требуются права администратора Windows. Подключение и выключение VORQELI никогда не изменяют HOSTS автоматически.

**Важное ограничение:** при наличии ручных записей в HOSTS сравнение GeoHide DNS ON/OFF по этим доменам недостоверно — Windows может использовать фиксированные IP независимо от настройки DNS. Для проверки GeoHide используй встроенную прямую проверку DNS с `-NoHostsFile` / `-DnsOnly` и сравнение DNS-серверов адаптера.

## Ограничения релиза

Функциональность проверена офлайн-тестами (без прав администратора и изменения сети). Реальная эффективность ALT-стратегий и совместимость записи системного HOSTS на конкретной Windows требуют испытаний. Подписанного стабильного Windows-релиза v1.0.0 пока нет.
