# VORQELI Connect 0.40.1 RC — реальный интерфейс

В версии 0.39.0 шесть PNG-макетов использовались как фон главного окна.
Прозрачные области отсылали действия старым обработчикам. Это было
несоответствием ожиданию полноценных настраиваемых экранов.

Новый модуль `src/vorqeli_connect/native_ui.py` рисует каждую строку,
каждую карточку, рамку и кнопку через `tkinter.Canvas`, исходя из данных
контроллера. Он не открывает изображения экранов и не показывает
демонстрационные состояния из макета. Иллюстрации целых экранов не используются. Изображениями остаются
только **оригинальный** `VORQELI-logo.png` и небольшие локальные иконки
Discord, YouTube, Telegram, ChatGPT и Microsoft; сами файлы не изменены.

## Действия

- Главная: включает/отключает *существующий* UnifiedController; статус
  «запущен» отражает состояние локальных модулей, не гарантирует доступности
  любого внешнего сервиса.
- Диагностика: пять реальных проверок с отдельными кнопками. HTTP 403/429
  не объявляется успехом. DNS, логи и Telegram Web доступны напрямую.
- История: локальные события (поле `action`, а не несуществующее `kind`),
  фильтры, страницы, добровольный экспорт JSON.
- О проекте: честный номер версии и состояния модулей, ссылка GitHub.
- Настройки: семь переключателей привязаны к существующему `save_settings`.
- Сеть: ALT1–ALT13 / AUTO, выбор DNS вне активного подключения,
  переход к менеджеру официального GeoHide HOSTS и восстановлению DNS.

## Что не меняли

`unified.py`, `geohide.py`, `geohide_doh.py`, `hosts_overlay.py`,
`geohide_hosts_feed*.py`, `engine_adapters.py`, `startup.py`,
`uninstall_safety.py` — остаются без изменений. Никакие сетевые настройки
не меняются при запуске патча или отрисовке интерфейса.

## Проверки перед публичным релизом

1. `py -3.12 -m pytest -q` — полный регрессионный набор.
2. `py -3.12 scripts/check_repo_layout.py` — комплектность файлов.
3. `py -3.12 scripts/verify_build_manifest.py` — SHA-256.
4. GitHub Actions Windows build — EXE, установщик, upgrade/uninstall.
5. Реальные Windows 10/11: UAC, трей, масштабирование 100/150/200%,
   ввод, восстановление DNS и HOSTS после ошибок, сон/перезапуск, сетевые
   ограничения Discord/YouTube/Telegram/ChatGPT/Microsoft.
6. Подпись EXE и установщика перед v1.0.0.

Старые PNG-макеты хранятся в исходниках как наследуемые ресурсы для
совместимости регрессионных тестов v0.39.0, но **не используются** новым
главным экраном. Их удаление из установщика требует отдельного изменения
сборки и тестов, чтобы не сломать успешный Windows CI v0.40.0.
