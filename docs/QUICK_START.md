# Быстрый старт VORQELI Connect

> Текущая версия: **v0.41.0 RC**. Windows 10/11 x64. Программа не является VPN и не гарантирует доступность определённых сайтов.

## 1. Установка

1. Перейдите в [Windows build](https://github.com/Zeihos/VORQELI/actions/workflows/windows-build.yml).
2. Выберите **успешный** запуск для ветки `main`.
3. В `Artifacts` скачайте `VORQELI-Connect-v0.41.0-Windows` и распакуйте архив.
4. Сверьте EXE и Setup с `SHA256SUMS.txt` в артефакте. Помните: проверка хэшей не заменяет цифровую подпись.
5. Запустите установщик `VORQELI-Connect-Setup.exe` и затем приложение. Для WinWS и системного DNS может потребоваться подтверждение UAC.

Перед обновлением полностью закройте приложение, в том числе через трей. Установщик защищён от обновления работающего экземпляра.

## 2. Первое подключение

1. Откройте **Настройки** и выберите используемые компоненты: **WinWS**, **Telegram**, **GeoHide DNS**.
2. В разделе **Сеть и стратегии** выберите **AUTO 1–13** или один профиль ALT1–ALT13. Переключение во время работы может потребовать переподключения.
3. Для GeoHide выберите IPv4 DNS либо DoH/HTTPS (при поддержке вашей Windows и после проверки настроек).
4. На **Главной** нажмите **«Подключить»**.
5. Откройте **Диагностика** и проверьте реальные результаты. Запущенный процесс не доказывает обход ограничений.

**GeoHide HOSTS применяется отдельно:** **Сеть и стратегии → HOSTS / ПРАВИЛА**. Изучите предпросмотр и подтверждайте изменения только если понимаете последствия. Не используйте сразу несколько утилит, которые одновременно редактируют системный HOSTS.

## 3. Telegram Desktop

Встроенный MTProto-прокси работает локально. Для Telegram Desktop откройте **Настройки → Продвинутые настройки → Тип подключения → Прокси → MTProto** и используйте адрес `127.0.0.1`, порт и secret, указанные приложением (типичный порт — `1443`). Вместо ручного ввода доступна ссылка `tg://proxy`.

**Telegram secret — конфиденциальные данные.** Не отправляйте его в Issue, скриншотах или журналах. Telegram Desktop и Telegram Web — разные сценарии; доступность одного не доказывает работу другого.

## 4. Отключение и восстановление

1. Нажмите **«Отключить»** и проверьте состояние каждого модуля.
2. Если были изменены DNS, воспользуйтесь кнопкой **«Восстановить DNS»** в разделе **Сеть и стратегии**.
3. Если применяли GeoHide HOSTS, выполните откат через **HOSTS / ПРАВИЛА**. Не удаляйте вручную чужие строки из HOSTS.
4. При конфликте с ручными изменениями программа может остановить автоматический откат — не игнорируйте предупреждение.
5. Только после восстановления настроек завершайте приложение в трее и удаляйте установщик.

Восстановительные данные находятся в `%APPDATA%\VorqeliConnect\`. Не удаляйте резервные журналы, пока восстановление не подтверждено.

## 5. Если что-то не работает

| Ситуация | Проверить |
| --- | --- |
| WinWS не запускается | Права администратора, защиту Windows, наличие сетевого драйвера и журнал WinWS |
| Telegram не подключается | Локальный порт, secret, настройки MTProto Telegram Desktop |
| DNS не восстановился | Резервный журнал, исходную конфигурацию адаптера, сообщения приложения |
| DoH недоступен | Поддержку DoH вашей сборкой Windows; не рассчитывайте на автоматическое переключение на IPv4 |
| Сервис вернул HTTP 403/429 | Это ограничение HTTP, а не успешный доступ к аккаунту |
| Окно закрыто, но модули работают | Проверьте значок VORQELI в системном трее |

Для ошибок подготовьте версию Windows, шаги воспроизведения, время ошибки и **очищенные от личных данных** журналы. Секреты, пароли, личные IP и содержимое HOSTS без проверки не публикуйте.
