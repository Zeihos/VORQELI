# VORQELI Connect — запуск за одну кнопку

1. Скачайте артефакт из GitHub Actions и запустите **`VORQELI-Connect-Setup.exe`**. Установщик разместит приложение в Program Files — это необходимо для безопасного автозапуска с повышенными правами без постоянных запросов UAC.
2. Запустите приложение. Если Windows запросит разрешение администратора, подтвердите его: WinDivert и системный DNS требуют прав.
3. Нажмите **Подключиться**. При первом запуске WinWS (~1,5 МБ) будет скачан с GitHub Flowseal и проверен по SHA-256; код Telegram уже находится в EXE.
4. Нажмите крестик — окно исчезнет, приложение останется в трее. В трее можно открыть окно и отключить подключение.
5. При следующем входе в Windows VORQELI запустится в трее и восстановит последнее желаемое состояние. Автозапуск возможен при наличии задачи Windows с наивысшими правами. Если задача не установилась, статус сообщит об ограничении.
6. Если перед выключением ПК нажали **Отключить**, при следующем запуске соединение автоматически НЕ включится. Если выбранный компонент неожиданно завершится при включённом состоянии, VORQELI попробует перезапустить его с ограничением до трёх попыток.

## Telegram один раз

Telegram Desktop → Настройки → Продвинутые настройки → Тип подключения → Прокси → MTProto:
адрес `127.0.0.1`, порт `1443`, секрет, который VORQELI подставляет в ссылку `tg://proxy` через кнопку **Открыть Telegram**. Для защиты он хранится в профиле Windows через DPAPI, а не как читаемый текст.
Секрет чувствителен: не отправляйте его другим людям. В настройках программы доступна кнопка открытия `tg://proxy` для подключения Telegram Desktop.

## Если пропал интернет после DNS-изменений

В главном окне откройте **Настройки → Вернуть исходный DNS**. Если программа не запускается, используйте штатные настройки Windows → Сеть → DNS: верните автоматический DNS (DHCP) или собственные адреса. Исходный конфиг VORQELI хранит в `%APPDATA%\VorqeliConnect\dns-restore.json`.

**Системный DNS в v0.19.0 использует обычный UDP/TCP к GeoHide, а URL DoH проверяется отдельно.** GeoHide не является VPN и не заменяет DPI-движок. Эффект DPI-профиля зависит от провайдера. В версии 0.19.0 проверяется базовый TCP-профиль, не вся библиотека стратегий Flowseal.
