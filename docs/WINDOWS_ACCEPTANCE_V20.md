# VORQELI Connect v0.20.0 — проверка локального DPI-движка на Windows

## До тестирования

1. Установить VORQELI через установщик в Program Files. Запустить и проверить `--doctor`.
2. При первом включении подключиться к сети: пакет Flowseal загружается из закреплённого релиза с проверкой SHA-256.
3. Снова выполнить `--doctor`, поле `dpi_integrity` должно быть `verified` (если DPI загрузился).
4. Отключить все компоненты; затем запустить снова **без Интернета**. Движок должен использовать проверенный кеш, без новой загрузки.
5. Пока приложение выключено, безопасно создать резервную копию и изменить **копию** кеша для теста: `dpi_integrity` должен стать `tampered`. Восстановить оригинальный файл, не запускать неизвестный EXE.
6. Проверить, что при неудачной повторной загрузке предыдущий кеш остаётся на диске, а приложение не заявляет, что он проверен.
7. Проверить действия антивируса, WinDivert, UAC, выключение Windows, трей и GeoHide по документу `WINDOWS_ACCEPTANCE_V19.md`.

**Безопасность:** manifest защищает кеш только при соответствующих ACL Program Files. В переносимом варианте с изменяемой пользователем папкой локальное вредоносное ПО может изменить и файлы, и manifest. Нужна цифровая подпись релиза и внешнее подтверждение подлинности.

## GitHub Actions

Завершение проверки требует успешной сборки EXE, установщика и сохранения `SHA256SUMS.txt` в Artifacts. SHA-256 помогает проверить неизменность файлов после загрузки, но без подписи не доказывает их происхождение.
