# VORQELI — пять сервисов и необязательный список GeoHide HOSTS (0.36.3)

## Диагностика

Диагностика содержит пять строк: Discord, YouTube, Telegram Web, ChatGPT,
Microsoft (Copilot, Designer, Xbox). Для Microsoft проверяются **три**
отдельных HTTPS URL, а строка сохраняет результаты для каждого. Проверки
запускаются вручную по кнопке и не изменяют настройки сети. HTTP 403, 404,
429 и другие ответы не объявляются «Доступен». Положительный HTTP ответ
не доказывает полноценную работу сайта, авторизации, переписки или игр.

## HOSTS

Встроенный необязательный файл содержит исходные 241 записи VORQELI
(включая Telegram Web/Flowseal) и нормализованный снимок GeoHide
от 18.10.2026. В опубликованном снимке GeoHide многие домены имеют 4 IPv4
адреса. Для совместимости с управляемым HOSTS выбрана **одна** запись на
домен: первый публичный IPv4 из полученного файла; это НЕ гарантирует
доступность и не является автоматическим DNS-балансировщиком. Уже имеющаяся
правильная Telegram-запись всегда имеет приоритет при объединении.

Внимание: все выбранные GeoHide IPv4 IP могут устареть; это внешний сервис,
через который могут проходить соединения. Не рекомендуется передавать
пароли, API-ключи или личные данные через непроверенные посреднические IP.
Рекомендуется официальный DNS/DoH поставщика, а не статический HOSTS.

Записи добавляются **только** через кнопку «HOSTS · ДОПОЛНИТЕЛЬНО» после
подтверждения и с правами администратора; на подключение и отключение
VORQELI они НЕ влияют. Конфликты с ручными записями блокируют запись.
Удаление затрагивает только управляемый блок, оставляя пользовательский HOSTS.

Если уже существует блок старого выпуска VORQELI, сначала удалите его через
тот же менеджер после ознакомления с содержимым, затем примените новый.

До выпуска необходимы Windows-проверки, проверка свежести IP и сценарии
восстановления. Эффективность ChatGPT/Claude не подтверждена этим патчем.
