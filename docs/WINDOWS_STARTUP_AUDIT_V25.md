# VORQELI Connect v0.25.0 — Windows Startup Audit

**Статус:** подготовлено для проверки на Windows 10/11; эта инструкция не подтверждает, что компьютер уже проверен.

## Зачем появилась v0.25

Windows может содержать два способа автозапуска: повышенную задачу Планировщика и `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
Приложение **не должно** стирать значение с таким же именем, если его команда не принадлежит VORQELI. Поэтому сравнивается точная команда для текущей установки и тип значения `REG_SZ`. `REG_EXPAND_SZ`, чужой EXE, дополнительные параметры и повреждённая запись считаются `untrusted`.

## Автоматический тест в GitHub Actions

В `windows-build.yml` предусмотрен шаг `Verify Windows autostart registration lifecycle`, выполняющий `python scripts/windows_startup_smoke.py` **после тестов и перед сборкой**.

1. Проверить отсутствие задачи и записи VORQELI (`startup_registration: missing`). При найденной записи тест намеренно завершится с ошибкой, ничего не удаляя.
2. Зарегистрировать только HKCU Run (без UAC и прав администратора), сверить результат `registration_status() == 'registry'`.
3. Удалить **только свою подтверждённую запись** в `finally`; убедиться, что статус снова `missing`.
4. Команда **не запускает** WinDivert, Telegram и GeoHide, не меняет DNS и не выполняет перезагрузку.

## Ручная проверка на тестовом ПК

1. На Windows 10/11 установите VORQELI в защищённый Program Files и проверьте, что файлы нельзя заменить обычным непривилегированным пользователем.
2. Вызовите `VORQELI-Connect.exe --doctor --doctor-output report.json`, прочитайте `startup_registration` и `startup_preference`.
3. Если статус `untrusted` или `unknown`, **не удаляйте неизвестную задачу/запись автоматически**. Проверьте их вручную и убедитесь, что они относятся к VORQELI. Не выполняйте сетевые тесты до устранения конфликта.
4. Проверьте сценарии `OFF → перезагрузка → OFF` и `ON → перезагрузка → ON`, а также закрытие окна в трей и восстановление DNS при отключении. Эти сценарии требуют административных прав и отдельного протокола результатов.
5. При проверке запуска с реестром учитывайте, что DPI и изменение системного DNS могут потребовать UAC после входа. Это не считается бесшумным автозапуском.

## Ограничения

- Совпадение команды — базовая проверка владения записью, не цифровая подпись. Защита от подмены бинарника отдельно зависит от ACL Program Files.
- Если путь установки изменился, прежняя запись HKCU Run может стать `untrusted`: её нельзя автоматически удалить. Сначала проверьте прежний путь и очистите запись вручную, только если она принадлежит старой версии VORQELI.
- На изолированном Windows-раннере проверяется только ветка HKCU Run; Task Scheduler, реальные UAC, перезагрузка, многопользовательские сеансы и сетевые драйверы остаются ручными блокерами релиза.
