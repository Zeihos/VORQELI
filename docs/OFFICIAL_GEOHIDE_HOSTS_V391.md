# VORQELI 0.39.1 — официальный GeoHide RU HOSTS (предрелизная интеграция)

## Источник

- https://github.com/Internet-Helper/GeoHideDNS/blob/main/hosts/hosts
- В веб-интерфейсе GeoHide: «Другие форматы» → RU → `hosts` → «Классический».
- При загрузке применяется только точный HTTPS URL `raw.githubusercontent.com/Internet-Helper/GeoHideDNS/main/hosts/hosts`. Редиректы блокируются.
- Проверяются маркеры формата, регион RU, дата источника, корректность IP/доменных имён, отсутствие частного/loopback-IP для внешних доменов, количество записей, размер и окончание файла.

## Почему отличается от предыдущей реализации

Старый встроенный VORQELI HOSTS — статический снимок; раньше каждому домену соответствовал только один выбранный IP. Новый модуль сохраняет **все уникальные IP-альтернативы** из классического формата официального файла. Он объединяет официальные домены с прежними дополнительными VORQELI/Telegram записями; официальный источник имеет приоритет при совпадении домена, вручную заданные HOSTS вне управляемых блоков никогда не переписываются. Локальные имена `localhost` и `ip6-localhost` из внешнего источника не включаются.

## Управление

В VORQELI открыть **Настройки → Сеть и стратегии → HOSTS / ПРАВИЛА → GEOHIDE RU**.

1. Нажать «ОФИЦИАЛЬНЫЙ RU». Если GitHub недоступен, скачать файл на сайте GeoHide и выбрать «ИЗ ФАЙЛА».
2. Изучить источник, число IP/доменов, число исключённых конфликтующих ручных доменов и сохранённых правил Telegram.
3. При осознанном согласии с перенаправлением доменов на сторонние IP нажать «ПРИМЕНИТЬ», подтвердить предупреждение UAC и действие.
4. Для отключения — «ОТКАТИТЬ»: собственный блок GeoHide удаляется, предыдущий VORQELI/Telegram-блок восстанавливается. Если блок изменён вручную, откат блокируется до ручной проверки.

Журнал восстановления: `%APPDATA%/VorqeliConnect/geohide-hosts-restore.json`. При удалении/переустановке приложение не должно удалять журнал до восстановления правил. Вся мутация HOSTS происходит только по явному подтверждению, не при запуске, установке патча, подключении или остановке сети.

## Ограничения и обязательные тесты до v0.40 RC

- Доступность Claude, ChatGPT и Microsoft не подтверждена фактом установки HOSTS. Содержимое через сторонние прокси может иметь существенные риски приватности/доверия.
- Системный DNS-браузера и браузерный защищённый DNS могут отличаться.
- Проверить на Windows: права NTFS/ACL HOSTS, сохранение исходных строк и переводов строк, повторное обновление, обновление при закрытом браузере и восстановление после аварии или перезагрузки.
- До публичного v1.0 требуется отдельно проверить деинсталляцию при активном GeoHide HOSTS. Этот патч сам НЕ включает автоматическую установку и удаление GeoHide HOSTS.
